# The Landscape of Taiwanese Music
Part of what inspired me to create this blog was because I found myself so fascinated by the incredible diversity that exists within Taiwanese music. For example, you can listen to a French-inspired album by Siri Lee ([李竺芯《水 Súi》](https://youtu.be/ehl-pc0syCU)) and then proceed to listen to Taiwanese Enka song by Chiam Nga-Bun 詹雅雯.
